# Parametric Turtle Art 🎨🐢

A Python script that generates visual parametric artwork using the built-in `turtle` and `math` modules. The program creates a geometric cat silhouette framed by radial color gradients and star accents.

![Turtle Art Preview](preview.png) <!-- Add your screenshot here -->

## Features

* **Parametric Math:** Uses trigonometric equations ($\sin$, $\cos$) to shape the silhouette.
* **Natural Color Palette:** Cycles through organic green tones for a turtle-inspired aesthetic.
* **Pure Python:** Uses built-in standard libraries (`turtle` and `math`) with zero external dependencies.

## Requirements

* **Python 3.x** (Includes `turtle` by default on Windows/macOS)

> **Note for Linux Users:** If `turtle` is missing, install `python3-tk` via your package manager:
> ```bash
> sudo apt-get install python3-tk
> ```
